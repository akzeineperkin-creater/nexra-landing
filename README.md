# Nexra — Инвестициялық симулятор 📈💡

> **Ғылыми жобаны қорғауға арналған интерактивті Scrollytelling презентациялық веб-сайты (Landing Page).**  
> **Автор:** Еркін Ақзейнеп, 11-сынып  
> **Бағыты:** Қаржылық сауаттылық, жасанды интеллект және білім беру технологиялары

---

## 🌟 Жоба туралы

**Nexra** — мектеп оқушылары мен жастардың қаржылық сауаттылығын тәжірибелік симуляция арқылы арттыруға арналған виртуалды инвестициялық платформа.

Бұл веб-сайт қазылар алқасына жобаның ғылыми мәнін, өткізілген 6 апталық эксперимент нәтижелерін (+1.7 есе білім өсімі) заманауи және интерактивті Scrollytelling форматында қорғауға арналған.

---

## 🚀 Негізгі модульдер мен құрылымы

1. **Animated WebGL Shader Hero:**
   - GPU-жеделдетілген WebGL шейдерлік фондық визуализациясы.
   - Заманауи typography, trust badge және бірден презентацияға апаратын тегіс скролл батырмасы.
   - Қараңғы ғарыштық Hero-дан ақшыл негізгі блокқа жұмсақ градиенттік ауысу (Light Mode Transition).

2. **Scrollytelling блогы (Sticky Layout):**
   - **01 / Мәселе (Тұтыну vs Инвестиция):** Жаңа iPhone 16 Pro (-40% құнсыздану) мен Apple акциясының (+312% капитал өсімі) контрасты, PISA 2022 статистикасы.
   - **02 / Платформа (Nexra симуляторы):** Заманауи браузер мокапы және ішіндегі видео/терминал интерфейсі.
   - **03 / Эксперимент және нәтиже:** Recharts интерактивті BarChart арқылы 6 апталық тәжірибелік өсім (+10 балл vs +6 балл, 1.7x артықшылық).
   - **04 / Қорытынды:** «Мен осы компанияның клиентімін бе, әлде иесімін бе?» басты тұжырымы және жетістік белгілері (Trophy, Target, Rocket).

3. **Ғылыми төлқұжат (Jury Passport):**
   - Қазылар алқасына арналған ресми құжаттама, ғылыми жаңалық және практикалық нәтижелер.

## 🛠 Технологиялық стек

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **UI Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Charts:** [Recharts](https://recharts.org/)
- **Icons:** [Lucide React](https://lucide.dev/) (строгие векторные иконки без эмодзи)
- **Language:** TypeScript

## 💻 Жобаны жергілікті компьютерде іске қосу

### 1. Репозиторийді көшіріп алу (Clone):
```bash
git clone https://github.com/<your-username>/nexra-landing.git
cd nexra-landing
```

### 2. Қажетті пакеттерді орнату:
```bash
npm install
```

### 3. Әзірлеу серверін қосу:
```bash
npm run dev
```
Браузерден [http://localhost:3000](http://localhost:3000) сілтемесін ашыңыз.

### 4. Оңтайландырылған өндірістік нұсқаны жинау (Production Build):
```bash
npm run build
npm start
```

## 🎥 Демо-видео қосу (Опционально)

Платформа мокапында нақты өзіңіздің видеоңыз ойнатылуы үшін:
1. Өз видеоңызды `demo.mp4` деп атаңыз.
2. Оны жобаның `public/` папкасына салыңыз (`public/demo.mp4`).
3. Видео файл қосылғаннан кейін браузер экранының ішінде автоматты түрде ойнатыла бастайды (`autoPlay loop muted playsInline`).
